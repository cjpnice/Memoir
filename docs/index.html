几秒钟即可开始

下载、运行，开始创建你的第一本相册。

1 下载并运行

从上方下载对应平台的可执行文件，然后运行：

# macOS / Linux chmod +x memoir-* && ./memoir-* # Windows memoir-windows-amd64.exe

2 在浏览器中打开

集忆会启动本地服务并自动打开浏览器。如果没有，请手动访问终端显示的 URL。

3 创建项目并导入照片

点击"新建项目"，填写标题，然后上传照片。支持 JPG、PNG、HEIC 和 HEIF。

4 AI 策划，然后导出

在设置中配置 AI API Key，点击"分析"，审核 AI 决策，生成叙事相册，导出为 HTML 或发布到 GitHub Pages。
